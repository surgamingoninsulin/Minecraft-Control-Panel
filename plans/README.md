# plans/README.md

Use this folder for task execution plans.

## Naming
- `YYYY-MM-DD-short-task-name.md`

## Lifecycle
- create -> in_progress -> completed

## Required Sections
- Goal
- Constraints
- Options (Plan 1/2/3 when relevant)
- Selected Plan
- Steps
- Validation
- Outcome

Reference template: `plans/PLAN_TEMPLATE.md`
